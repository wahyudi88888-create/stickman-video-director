# Ide Konten — Stickman Video Director (fork saya)

Repo ini adalah fork dari `kaomei/stickman-video-director` (MIT License, lihat `LICENSE`).
Semua ide konten lewat sini, supaya tidak hilang di chat.

## Alur

1. Tulis ide baru sebagai file di `ideas/` — pakai `TEMPLATE.md`.
2. Saya (Muse) baca ide itu, lalu produksi:
   - script + visual prompts (gaya Stickman / MS Paint, 9:16)
   - gambar / keyframe, voiceover, musik bed + SFX, dan video — pakai Muse
   - batas jujur Muse: video max 6 klip per batch, masing-masing ~10 detik
3. Hasil produksi dicatat di file ide itu (status + lokasi file).
